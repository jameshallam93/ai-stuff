# skylz

This repo will hold a set of lightweight development skills. They are intended to support different stages of the software lifecycle and offer distinct personas matched to the task at hand.

## Layout

Each installable skill lives in `skills/<skill-name>/SKILL.md`.

## Install

To make a skill available in any Codex session, copy each skill directory into `~/.codex/skills/`, for example:

```text
~/.codex/skills/super-senior/SKILL.md
~/.codex/skills/intrepid-junior/SKILL.md
```

After copying or syncing the directories, restart Codex so it reloads the available skills.
